# UIFramework

一套成熟、可商用的 **Unity uGUI 框架**，设计灵感来自原神 (MoleMole.UIManager)、GameFramework、LoxodonFramework 等。

> 🚧 本仓库正在分阶段搭建中。第一阶段 **P1 核心骨架** 将通过独立 PR 提交。

## 路线图

| 阶段 | 内容 | 状态 |
|------|------|------|
| P1 | 核心骨架：UIRoot + 分层 + UIManager + Config + Context 生命周期 | 🚧 进行中 |
| P2 | 栈式导航 UINavigator + 返回键 | ⏳ |
| P3 | 资源加载（Addressables 实现） | ⏳ |
| P4 | 对象池 / 虚拟列表 | ⏳ |
| P5 | 消息中心 MessageCenter | ⏳ |
| P6 | 转场动画 IUITransition | ⏳ |
| P7 | MVVM 数据绑定 BindableProperty | ⏳ |
| P8 | Editor 工具：组件自动绑定 / 代码生成 | ⏳ |
| P9 | 示例 Demo 与单元测试 | ⏳ |
